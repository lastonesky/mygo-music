# 快速切歌时取消旧音频加载

连续切换 A → B → C → B 时，离开的音频加载应立即取消。只关闭音频输出可能无法唤醒阻塞在下载读取中的解码器，旧 URL 请求、部分下载和等待预取也可能继续占用资源。

每次加载使用独立的取消上下文，覆盖 URL 获取、等待预取、打开解码器及结果等待 UI 派发期间。切歌、停止及缓存目录迁移会取消该上下文，并关闭当前下载来唤醒阻塞读取。已接管的预取归当前加载所有，后续切歌也会取消它；取消等待前一首下载的预取不会关闭仍在播放的前一首。

FLAC 保留增量播放：首个完整帧到达后即可开始解码。取消打开完整缓存歌曲不会将缓存视为损坏或删除它。过期结果仍通过原有加载代次校验丢弃。

回归入口：`internal/player/load_cancel_test.go`，覆盖快速往返、阻塞解码、URL 获取、已接管与等待中的预取、派发前取消和完整缓存保留。
